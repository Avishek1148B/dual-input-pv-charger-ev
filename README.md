# Dual-Input PV Charger for Lightweight EVs

ESP32-based control and real-time monitoring system for a dual-input photovoltaic (PV) charger designed for lightweight electric vehicles.

## 📌 Project Overview

This project focuses on the development of a dual-input PV charging system for lightweight EV applications. An ESP32 is used for system-level control, monitoring, user interface, wireless connectivity, and coordination of charging and MPPT operation.

The system continuously monitors PV input, battery parameters, charging power, and overall charger status while providing both local and remote monitoring.

## ⚡ Key Features

- Dual-input photovoltaic (PV) charging architecture
- ESP32-based control and real-time monitoring
- Maximum Power Point Tracking (MPPT)
- Battery charging supervision
- Real-time PV and battery parameter monitoring
- Onboard LCD display for local monitoring
- Blynk IoT dashboard for wireless monitoring
- Wi-Fi connectivity and network provisioning
- WiFiManager-based configuration
- Real-time battery and fault notifications
